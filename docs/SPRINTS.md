# Alvinmunk Season 0

## Campaign Structure
- **Public quest**: Unlimited participation, XP-based rewards
- **Referral quest**: Team-based progression with shared rewards
- **Small bounty pools**: Fixed-size pools with claim limits (e.g., "First 50 to 60 XP get 1 USDC")

## Treasury Planning
- Fixed pools enable exact budgeting via `max_claims × amount`
- Daily cap remains for system-wide spend control
- On-chain claim counters eliminate manual pool management
